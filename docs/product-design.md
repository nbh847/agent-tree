# 产品设计草案

## 目标与范围

在用户现有终端旁显示一棵目录树，同一目录中的 Agent 会话集中展示。用户继续在原终端工作，通过侧栏快速判断哪些会话在执行、哪些需要处理，并切换到目标会话。

已确定采用 tmux 方案：在当前 tmux window 左侧创建专用 pane 承载 TUI。首版以 macOS 上实际运行的 tmux 为目标，覆盖所连接 server／socket 内当前有 client 附着的 session、window 的 pane，包括普通 shell；没有 client 附着但当前进程树仍能识别到 Claude Code／Codex 的 pane 同样纳入，不因 detached 隐藏仍存活的 Agent，重启侧栏后也适用。仅靠历史启动命令不能证明 Agent 仍存活；普通 detached shell 与未知程序不自动纳入，其他 socket 和 tmux 外部终端不自动纳入。**保留规则**：侧栏自身的导航会 `switch-client`，把 client 从原 session 移走使其变为 detached；为此本次侧栏运行期间曾附着过的 session 会一直保留，避免用户「选了一个窗口，原来那个就没了」。这里的「聚合」指逻辑分组，不搬移用户 pane；侧栏本身会占用列宽并改变当前 window 的布局。侧栏绑定启动它的 tmux client，跟随原生 window／session 切换，只迁移自建 pane，保留当前输入焦点。

## 侧栏信息与交互

```text
 会话  ·  3 个
──────────────────────────────
▾ [agent-tree]  ~/workspace  2
  ├─ Codex
  └─ Shell
▾ [kzz-radar]   ~/workspace  1
  └─ Codex
```

会话名称右侧紧随四列宽、两行高的图案，与名称垂直居中对齐；条目使用三行区域，名称放中间一行，图片画布上下留白：Codex 使用用户指定的 OpenAI 结形图案，Claude Code 使用 Claude 图案，普通 Shell 使用终端窗口 `>_` 图案；未知身份保留 `?`。图标反映现有发现逻辑的会话身份，随快照刷新变化，不表示任务执行状态。首版图片支持 iTerm2／tmux；不支持时回退 `O`／`C`／`$`，名称保持可读。图片每次启动只上传一次；显示位置随 tmux 保存的标记重绘，滚动按视口自然裁剪，折叠后隐藏行随文字移除，窄栏优先名称。两侧焦点切换不重新上传图片。

暗色主题：近黑底、灰次要文字、绿色目录名、蓝色选中竖线。默认宽度为窗口的 24%（原 30% 缩小五分之一），显式 `--width` 参数仍可覆盖。目录行用方括号显示目录名、空间充足时显示的暗淡父级路径与右对齐的会话数；会话行用连接线 `├─`／`└─` 缩进，子会话名称统一使用普通正文色（浅灰），与绿色路径根节点区分。树线之间留出一行呼吸空间，顶部标题和底部提示留白；选中行使用蓝色竖线与低调的背景块并铺满整行。界面用 textual 实现；行按显示列宽截断而非折行（中文按两列计）。颜色不表示执行状态，执行状态识别尚未实现，不得据此判断任务是否在执行。首次扫描完成前显示「正在扫描会话…」占位帧。

进入其他 session 的会话时会执行 tmux `switch-client`：把你发起操作的那个终端一起切到目标 session，原 session 变为 detached。这是「定位到对应终端」的固有代价——一个 tmux client 同一时刻只能看一个 session。跳转多次后可能出现两个终端停在同一个 session 上，此时侧栏对该 session 只列一条（两边看的是同一个窗口）。轻量的浏览（`↑`／`↓`）绝不触发它。

**退出侧栏时必须把被带走的终端送回它原来的 session**（仅当它仍停在被带去的位置，用户自己切换过则不干预）。这样避免导航把用户终端长期留在别的 session；仍存活的 Agent 即使 detached 也必须可见，普通 detached shell 仍遵循附着与本次保留规则。

支持展开／折叠与当前会话高亮。原生切换 window／session／pane 后，高亮同步到当前用户 pane，自动展开对应分组并滚动到所在行；返回侧栏浏览时保留用户选择，其他 client 的活动不抢走侧栏。`↑`／`↓` 只在可见子会话行之间移动高亮，跳过路径根节点与已折叠的子会话，到达首尾时停留，不改变当前视图；`Enter`（或鼠标点击会话）**进入选中会话**--切换视图并把输入焦点交给目标 pane；`→` 与 `Esc` 与 `Enter` 等价，不向 Agent 发送这些按键；`n` 或路径节点右侧的 `[+]` 按钮在对应目录下新建一个 session（默认 shell），建好后把 client 与侧栏一起带过去，按钮点击只触发新建，不触发会话导航或折叠；目录未知或只读浏览模式不显示按钮。这是侧栏唯一会新建终端的操作，且只新增 session、不改动既有 pane。选中目录组只展开／折叠，不切换终端。侧栏旁的用户 pane 全部关闭（如 shell 执行 `exit`）时自动补位：优先迁移到被关会话所在目录分组的第一个会话并把焦点交给新 pane，该分组不在了取整个列表的第一个；列表为空则退出侧栏，session 与终端交由 tmux 自然收摊。数据刷新、初次加载和程序恢复选择不触发导航（上述补位除外）；状态更新不抢焦点、不突然改变行顺序。完整路径与状态来源可在详情中查看。首次进入无数据时区分「没有 Agent」「无法读取目录」「宿主未连接」，不统一显示为空。

## 目录归属

默认按 **Git 仓库根目录**分组：从会话工作目录逐级向上查找 `.git`，命中即以该目录成组，因此同一仓库下不同子目录的会话（如 `kzz-radar` 与 `kzz-radar/web`）聚在一起，项目名也稳定显示为仓库名。只做文件系统判断，不调用 `git`。不在任何仓库内时退回本机规范化的完整工作目录；软链接解析到同一真实目录后自然合并，不可解析时保留原路径并标注。相同 basename 的不同路径不能合并。未知目录进入「目录未知」，不能猜成侧栏启动目录。家目录本身不作为仓库根，避免 dotfiles 配置把所有家目录下的会话并成一组。

worktree 与 submodule 的 `.git` 是文件而非目录，同样算命中，因此各自独立成组。会话工作目录发生变化后更新归属；Agent 内部目录无法读取时沿用最近可信目录并标注来源。远程主机相同路径不能与本地或其他主机合并，首版不保证远程发现。

## 首版功能优先级

| 优先级 | 功能 | 验收要点 |
| --- | --- | --- |
| P0 | 宿主会话发现与目录树 | 启动前已存在的会话也可发现；新增、切目录、关闭后准确更新。 |
| P0 | Agent 名称与标识 | 首批计划 Claude Code／Codex；普通 shell、node 及同名文本不能误认，未知程序保留降级。 |
| P0 | 侧栏导航 | 切换到准确的 session／window／pane；失效目标提示，不误操作另一个会话。 |
| P0 | 生命周期安全 | 关闭侧栏不结束 Agent、不发送输入，tmux 退出仅回收自建 pane。 |
| P1 | 执行状态 | 显示执行中、空闲、等待输入／确认、未知，并标注证据来源与过期。 |
| P1 | 图标与显示适配 | iTerm2 中使用 Codex／Claude Code／Shell 图片图标；不可用时回退字符标识，始终保留名称；滚动、折叠、迁移后对齐且无残影。 |
| 后续 | 更多 Agent 与辅助信息 | 根据实际样本扩展 Gemini CLI／OpenCode 等，Git 分支与历史项目按需求另行设计。 |

首版不做任务调度、对话存档、自动恢复 Agent、额度监控、远程编排或全新终端模拟器。

## 核心验收场景

1. 同目录分别打开 Claude Code 与 Codex，归入同一组；同种 Agent 的两次启动不合并成一条。
2. 两个不同完整路径具有相同目录名，保持独立；软链接入口按规则合并；父子目录与 worktree 独立。
3. 在启动侧栏前已开的会话、新开的 window／pane 和同一 tmux server 内跨 session 会话都能被发现；无权限时明确说明覆盖范围。
4. Agent 退出回到 shell 后移除 Agent 标识；会话关闭后清理条目，焦点切换遇到过期 ID 不发送输入。
5. 历史输出含「等待确认」但当前实际执行时，不错误报警；长时间无输出不直接判为完成。
6. 多个 window、session 和 tmux client 场景，避免重复条目；导航只作用于发起操作的 client，不切换其他 client 的 session。共享 session 的当前 window 变化可能影响其他 client，需验证并明确提示。
7. 中文、空格路径、窄屏、无 Nerd Font、宿主断连与重连均有明确回退。

## 已确定与待验证

- 已确定使用 tmux TUI 侧栏；默认按完整路径分组，父子目录与 worktree 独立。
- 技术待验证：已有 pane 的 cwd 与进程识别、跨 session 导航、每个 window 的侧栏保持方式、多 client 影响及布局恢复。
- 精确状态需按 CLI 版本验证事件或 hook 支持；未验证前不能承诺所有 Agent 自动识别执行状态。
